# GNU sha256sum-min

The `Silmaril.Apps.Sha256sum` subtree contains a generated executable image
and proof support derived from GNU coreutils/gnulib material.  It is retained
in this draft only to make the licensing boundary reviewable.  The subtree is
GPLv3 material and is not part of the final permissive promotion unless the
repository accepts the corresponding license and provenance decision.

The public freestanding `apps/sha256-cli` image is a separate artifact and is
not covered by this notice.
