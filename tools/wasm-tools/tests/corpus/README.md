# Vendored binaries of the wasm-tools differential suites

Small binaries the corpus differentials (`diff.sh`, `dump-diff.sh`, `meta-differential.sh`,
`meta-malformed.sh`) and the benchmarks read, so that the suites need no file outside
`tools/` of this repository. `SHA256SUMS` lists their digests; `pins.sh`
(`wt_corpus_check`) checks them before a suite runs. The other inputs are fetched by hash
(`fetch-pins.sh`): the spec testsuite, the wasm-tools source tree and the two WASI preview1
adapters of wasmtime v50.0.1.

The large debug build of `cat.wasm` (3.1 MB, with DWARF), which `addr2line/differential.sh`
and the benchmarks also read, is not vendored: set `WT_CAT_DEBUG` to its path (its SHA-256
is pinned in `pins.sh`); the cases that need it are skipped otherwise.
