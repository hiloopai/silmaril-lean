# Proofs

Good, non-trivial proofs, mirroring the header tree: `Silmaril/Proofs/<Region>/<Topic>/…`
proves statements headed in `Silmaril/<Region>/<Topic>/Thms.lean`.

- Semi-stable: other topics must not import these modules; they go through the
  `Thms` header instead.
- May use `Raw` proofs as valid but ugly steps.
