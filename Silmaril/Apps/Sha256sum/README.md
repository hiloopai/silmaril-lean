# GNU sha256sum proof area

This subtree is retained only in the process-promotion draft. It contains the
generated `sha256sum-min` image and proof support derived from GNU
coreutils/gnulib material. See [`NOTICES/GPLv3/SHA256SUM-MIN.md`](../../../NOTICES/GPLv3/SHA256SUM-MIN.md).

The permissive freestanding demo is `apps/sha256-cli`; it has a separate image
and hash and does not use this subtree.
